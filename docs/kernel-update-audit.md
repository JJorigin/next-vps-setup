# 1.2 审计与验证范围

本页说明已执行的检查及其验证边界。测试仅使用本地临时目录和一次性虚拟机，没有连接用户的公网服务器。

两份脚本的Bash语法检查、175项本地隔离测试、嵌入代码和SHA256一致性检查通过。

## 检查范围

- 两个脚本的Bash语法和源码审阅。
- 动态内核识别、Debian包版本比较、精确删除清单和APT事务保护。
- 运行中的内核构建与目标amd64启动镜像一致，名称相同但构建不同的内核会被拒绝。
- 重启续行、错误启动目标、失败停止、状态保存及清理中断恢复。
- 最早任务准备阶段的复制、写入和服务启动失败，以及原路径相同内容的恢复。
- 独立官方源的使用范围，以及现有源文件的保留。
- 独立软件包下载缓存、宿主缓存保留、最终索引权限及受限的APT临时链接处理。
- Debian 13 官方密钥符号链接的识别、异常密钥文件拒绝及密钥包升级后的配置一致性。
- 三个官方仓库索引的中断恢复，以及合法空软件包索引的兼容处理。
- 任务阶段和结果显示、下一次root交互登录提示及提示清理。
- 原有SSH、Swap、Fail2ban、气球驱动配置等保留检查。
- 四份共享代码的构建校验，缺文件或异常标记时停止；只读检查模式不修改输出。

测试使用临时目录、虚构软件包记录及系统命令替身；实际APT协议检查也重定向到隔离目录，并使用拒绝执行的dpkg替身，避免变更测试宿主的软件包。官方源隔离还使用真实APT配置解析和URI预览检查，未执行软件安装。

## Debian 13 虚拟机验证

最终交付脚本在三台全新本地虚拟机上完成初始化、两次自动重启、独立检查及一次性登录通知清理：

| 测试内存 | 原内核系列 | 初始化内存策略 | 结果 |
|---|---|---|---|
| 512MiB | cloud amd64 | 1GiB Swap，优先级10，swappiness=10 | 通过 |
| 1GiB | 标准amd64 | 1GiB Swap，优先级10，swappiness=10 | 通过 |
| 2GiB | cloud amd64 | 不新建Swap | 通过 |

使用真实APT 3.0.3、systemd 257及Debian官方密钥布局；核对了SSH配置、现有APT源文件的哈希保留，以及任务文件清理。网络校时未同步时按设计警告并继续。

三台机器的内核维护也完成新启动核验、旧内核动态清理及独立检查，只保留目标镜像包和原系列元包。标准内核测试从旧元包、目标镜像未安装的基线开始，实际下载和安装新镜像后重启；cloud测试覆盖从旧内核启动及目标已安装的两种情况。Swap、SSH及相关配置保持，内核维护通知显示一次后清理。

额外检查通过：

- 官方签名索引实际更新、权限异常索引拒绝、APT临时链接恢复。
- 只下载不安装的缓存对照：私有缓存重新获取匹配官方SHA256的软件包，不复用宿主同名同大小的错误缓存；清理后宿主缓存标记保留。
- 真实IPv4和IPv6来源各提交五次错误密码，前四次未封，第五次封禁，之后SSH数据包被阻断。
- 内核维护及重启后，永久封禁记录恢复，原IPv4和IPv6来源仍被阻断。
- 耗时95秒的真实systemd服务自清理回归，确认删除服务定义后不会因脚本自身重载而恢复默认90秒超时。

较早的测试候选曾在慢速虚拟机中暴露服务自清理超时问题。修复后重新建立三台干净虚拟机验证，没有把旧候选的成功结果作为最终脚本的验证结果。

## 验证边界

本地虚拟机验证不等于覆盖所有商家、引导器、第三方软件或异常磁盘状态，也不构成绝对安全保证。首次使用应选择有备份、能通过商家控制台恢复的机器。ShellCheck未执行。

服务显示正常不等于业务连接一定正常，完成后仍需实际连接业务服务。登录提示面向常见Bash登录环境，其他Shell应使用结果查询命令。

APT清理不是原子事务；维护钩子失败时，可能已有部分旧内核被删除。脚本会停止并保留排查和恢复资料，审计时应结合日志与实际软件包状态。
